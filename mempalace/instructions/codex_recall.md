## MemPalace recall

Your conversations are captured into a local MemPalace. Earlier sessions are
retrievable — use them instead of guessing or asking the user to repeat
themselves.

**Search the palace before answering** any question about:

- prior work, decisions, or why something was done a particular way
- people, projects, or named things the user refers to as already known
- anything the user phrases as though you should already know it
  ("the plan we agreed", "that bug from last week", "what did I say about…")

Use the `mempalace_search` MCP tool. Quote what comes back **verbatim** —
never paraphrase stored content, and never present a summary as if it were
the user's words.

If the palace returns nothing, say so plainly. Do not invent a recollection.
